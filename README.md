## Анализ распределения событий ИБ

Общая структура: В ходе анализа обработано 100 событий безопасности.

Лидер по частоте: Самым частым событием является MALWARE-CNC Win.Trojan.Jadtre variant outbound connection (12 инцидентов). Это указывает на активные попытки исходящих подключений трояна Jadtre к командным центрам (C&C).

Равномерность: Остальные 8 типов событий (эксплойты Windows/Oracle, подозрительная активность MySQL, NETBIOS атаки) распределены абсолютно равномерно — по 11 инцидентов на каждый тип.

Вывод: Атака имеет смешанный характер, сочетая активность вредоносного ПО (Jadtre) и попытки эксплуатации уязвимостей различных сервисов.
